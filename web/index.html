What the agent does

It delivers clarity, not a promise.

  • Publishes a live Spot or Futures briefing through the Seller Agent.
  • Uses Binance MCP data and runtime tool discovery when connected.
  • Runs DeltaZero style risk gates before any executable proposal.
  • Free agent access through MCP, CLI, and HTTP, with optional real B402 settlement.
  • Records real Binance order evidence only. No simulated fills or receipts.

Hard boundaries

The control room can say no.

  • No withdrawals, transfers, or credential handling in Signal402.
  • Every order needs dashboard approval and a final CONFIRM.
  • Futures are isolated margin, maximum 3x leverage, maximum 10 USDT notional.
  • Neutral and COIN M Futures paths are report only in v1.
